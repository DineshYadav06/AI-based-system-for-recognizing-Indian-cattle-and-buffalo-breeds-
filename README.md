# 🐄 AI-based System for Recognizing Indian Cattle and Buffalo Breeds

An AI-powered image classification system for recognizing **Indian Cattle and Buffalo Breeds** using **Deep Learning** and **Computer Vision** techniques.

The project uses multiple Convolutional Neural Network (CNN) architectures and Transfer Learning models to classify cattle and buffalo breeds from images with high accuracy.

---

## 📌 Project Overview

Livestock breed identification is important for breeding, farm management, veterinary services, and agricultural research.

This project automatically identifies Indian cattle and buffalo breeds from images using Deep Learning models such as:

- Custom CNN
- MobileNetV2
- EfficientNet-B4
- EfficientNet-B7
- SVM Classifier

---

## 🎯 Objectives

- Build an AI model for cattle and buffalo breed recognition.
- Compare multiple deep learning architectures.
- Improve prediction accuracy using Transfer Learning.
- Deploy the trained model using Flask API.
- Provide an easy-to-use image prediction system.

# 🚀 Installation

Clone the repository

```bash
git clone https://github.com/DineshYadav06/AI-based-system-for-recognizing-Indian-cattle-and-buffalo-breeds.git
```

Move into project

```bash
cd AI-based-system-for-recognizing-Indian-cattle-and-buffalo-breeds
```

Install dependencies

```bash
pip install -r requirements.txt
```

---

# ▶️ Run Flask API

```bash
cd cnn-api

python app.py
```

The Flask server will start locally.
